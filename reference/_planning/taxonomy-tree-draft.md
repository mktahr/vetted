# Function → Sub-function → Specialty tree — DRAFT input for the taxonomy expansion design pass

Source: Matt, 2026-07-12 (iterating with a separate Claude chat). Explicitly NOT exhaustive and NOT final —
an example of the shape and breadth. Categorization opinions inside are unsettled (e.g. Matt leans toward
